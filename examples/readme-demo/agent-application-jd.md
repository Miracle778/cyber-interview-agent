# 拾光智能｜Agent 产品工程组｜AI Agent 应用工程师

团队负责面向企业知识工作场景的 Agent 产品研发，关注可控执行、工具编排、评测与可观测性。

## 岗位要求

- 3 年以上后端或 AI 应用研发经验，具备扎实的软件工程能力。
- 熟悉 Python、FastAPI 和主流 LLM API，能够设计稳定的结构化输出链路。
- 理解 Tool Calling、RAG、上下文管理和多步骤 Agent 工作流。
- 有任务恢复、人工确认、权限边界、评测集或 Agent 可观测性实践。
- 能够将业务目标拆分为确定性流程与模型判断，并说明二者的边界。
- 有 LangGraph、OpenAI Agents SDK 或同类编排框架经验者优先。
